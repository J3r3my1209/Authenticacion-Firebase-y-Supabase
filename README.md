Este proyecto consiste en el desarrollo de una aplicación web ligera en React enfocada en la implementación de sistemas de autenticación de usuarios, permitiendo comparar el flujo de Login y Registro mediante la integración de Supabase y Firebase. Desarrollado por Alejandro Fabara, Jeremy Vivas y Alex Perugachi, el aplicativo demuestra cómo gestionar identidades de forma segura y eficiente en el frontend, aprovechando las capacidades de bases de datos relacionales y servicios en la nube para ofrecer una experiencia de acceso funcional y moderna.
